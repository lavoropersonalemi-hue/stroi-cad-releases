# STROI CAD — versioni

Questo repository contiene **solo gli installer** di STROI CAD per Windows, nella sezione [Releases](../../releases). Non c'è codice sorgente.

- **Per usarlo serve un account STROI** con un piano che include il CAD. Senza il permesso l'app si apre in sola lettura (vedi, misuri, stampi).
- Il programma non è ancora firmato: Windows può mostrare l'avviso SmartScreen («Esegui comunque»).
- L'app controlla da sola le nuove versioni, ma solo quando gli aggiornamenti sono attivi, e chiede sempre prima di scaricare e installare.

Assistenza: scrivi a chi ti ha dato accesso al pilota, allegando il rapporto di «Aiuto → Segnala un problema».
